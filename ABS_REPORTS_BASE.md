# База структуры Tolubay ABS

Статус: проверено чтением 15 сентября 2026 года. В базу не включены анкеты,
номера счетов, суммы, операции, логины или пароли.

## Логика данных

1. Поиск клиента возвращает сводную карточку и её ABS ID.
2. Для известного ABS ID читается анкета в режиме `isShow=True`.
3. Массив счетов нельзя получить глобально: он читается только для одного
   известного клиента через `GetDepositsByCustomerId`.
4. Формирование отчёта требует отдельного проверенного контракта формы:
   точного маршрута `Execute`, параметров и формата. Скачивание является
   отдельным шагом после успешного формирования.

## Массив счетов

Запрос: JSON `{"customerId": <integer>, "showAll": false}` на
`/Deposits/Customer/GetDepositsByCustomerId`.

Ответ содержит `data.Deposits`. Для каждого элемента используются:

- `MainAccountNo` или `AccountNo` — номер;
- `CurrencyID`, при наличии `CurrencySymbol` — валюта;
- `DepositAccountStatusID` — технический статус;
- `CloseDate` — признак закрытого счёта;
- при наличии `AccountName` и `OpenDate` — название и дата открытия.

## Операционный дневник

Есть два зафиксированных исторических шаблона: кассовый журнал по приходу и
кассовый журнал по расходу. Их набор параметров одинаков:

`Branch.All`, `Branch.Value`, `Office.All`, `Office.Value`, `User.All`,
`User.Value`, `Currency.All`, `Currency.Value`, `ReportDate.Date`,
`FileFormat.Value`, `Value`.

`*.All` выбирает весь соответствующий справочник; `*.Value` задаёт один элемент.
`ReportDate.Date` задаёт операционный день, `Value` — формат результата.

## Проверенный текущий статус

Меню ABS всё ещё содержит 12 стандартных разделов отчётов и множество
дополнительных отчётных разделов. Но прямые GET-переходы по прежним 12 маршрутам
возвращают «Страница не найдена», а каталог дополнительных отчётов возвращает
HTTP 500. Поэтому `specs/tolubay-report-forms.json` — это снимок структуры от
20 августа, а не подтверждённый текущий контракт выполнения. До повторного
захвата актуальных форм запуск отчётов по старым `Execute`-маршрутам не должен
считаться надёжным.

Машиночитаемый итог проверки: `specs/tolubay-live-validation-2026-09-15.json`.
