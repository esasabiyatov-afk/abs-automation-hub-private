# Tolubay: отчёты и очередь печати

Для офисного компьютера без Python скопируйте всю папку `release` и запустите
в ней `START_PORTABLE_REPORTS.bat`. Приложение откроет лёгкую локальную страницу
в браузере, например Chrome.

В рабочей копии проекта `START_REPORTS_APP.bat` сначала запускает этот EXE, а
при его отсутствии использует переносимый Python для разработки.

Сейчас в интерфейсе оставлен только «Сводный мемориальный ордер». Он строится
по всем сотрудникам выбранных филиала и отделения: вручную вводить коды или
ФИО сотрудников не нужно. Остальные отчётные возможности сохранены в коде,
но временно скрыты из интерфейса.

Пароль используется только для текущего подключения и очищается из поля после
входа. Очередь существует только в памяти. Скачанный файл сохраняется в
выбранную пользователем папку ровно в виде, полученном от ABS: приложение не
меняет его содержимое, форматирование или параметры печати. Приложение не
изменяет данные клиентов, счетов или документов ABS.

Кнопки «Выше» и «Ниже» задают порядок подготовки файлов к ручной печати.
TLS-режим запуска сохранён совместимым с существующим BAT (`--insecure`).
