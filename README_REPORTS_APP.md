# Tolubay: отчёты и очередь печати

Для офисного компьютера без Python используйте `release/TolubayReports.exe`:
скопируйте файл на компьютер и запустите двойным щелчком. Приложение откроет
лёгкую локальную страницу в браузере, например Chrome. Excel требуется только
для подготовки и печати файлов XLS.

В рабочей копии проекта `START_REPORTS_APP.bat` сначала запускает этот EXE, а
при его отсутствии использует переносимый Python для разработки.

Приложение умеет добавлять в очередь и скачивать по заданному порядку:

- выписки по счёту в PDF или XLS;
- стандартные отчёты ABS с редактируемыми параметрами формы;
- отчёты по XLSX-шаблону;
- дополнительные отчёты из доступного каталога ABS.

Пароль используется только для текущего подключения и очищается из поля после
входа. Очередь существует только в памяти. Скачанные отчёты сохраняются в
выбранную пользователем папку. Обычные отчёты не печатаются автоматически.
Для «Сводного мемориального ордера» можно включить печать на принтере Windows
по умолчанию после подготовки файла. Приложение не изменяет данные клиентов,
счетов или документов ABS.

Кнопки «Выше» и «Ниже» задают порядок подготовки файлов к ручной печати.
TLS-режим запуска сохранён совместимым с существующим BAT (`--insecure`).
