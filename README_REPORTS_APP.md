# Tolubay: отчёты и очередь печати

Для офисного компьютера без Python скопируйте всю папку `release` и запустите
в ней `START_PORTABLE_REPORTS.bat`. Приложение откроет лёгкую локальную страницу
в браузере, например Chrome.

В рабочей копии проекта `START_REPORTS_APP.bat` сначала запускает этот EXE, а
при его отсутствии использует переносимый Python для разработки.

Сейчас в интерфейсе оставлен только «Сводный мемориальный ордер». После
подключения приложение читает актуальный справочник сотрудников ABS и выводит
имена с флажками. Пользователь выбирает нужных сотрудников, а внутренние коды
ABS не отображаются и вручную не вводятся. Для каждого выбранного сотрудника
создаётся отдельный файл в заданном порядке. Остальные отчётные возможности
сохранены в коде, но временно скрыты из интерфейса.

Пароль используется только для текущего подключения и очищается из поля после
входа. Очередь и загруженный справочник сотрудников существуют только в
памяти. Каждый скачанный мемориальный ордер проходит подготовку к печати:
очищается область после строки «Контролер:», подгоняются строки и рабочие
колонки, настраивается размещение по ширине страницы. Отдельная галочка по
явному выбору пользователя печатает обработанные файлы по порядку на принтере
Windows по умолчанию. Приложение не изменяет данные клиентов, счетов или
документов ABS.

Кнопки «Выше» и «Ниже» задают порядок подготовки файлов к ручной печати.
TLS-режим запуска сохранён совместимым с существующим BAT (`--insecure`).
