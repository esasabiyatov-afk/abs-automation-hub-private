# Tolubay: отчёты и очередь печати

Запустите `START_REPORTS_APP.bat`. BAT открывает лёгкую локальную страницу в
обычном браузере; дополнительные библиотеки, внешний сервер и установка Python
не нужны.

Приложение умеет добавлять в очередь и скачивать по заданному порядку:

- выписки по счёту в PDF или XLS;
- стандартные отчёты ABS с редактируемыми параметрами формы;
- отчёты по XLSX-шаблону;
- дополнительные отчёты из доступного каталога ABS.

Пароль используется только для текущего подключения и очищается из поля после
входа. Очередь существует только в памяти. Скачанные отчёты сохраняются в
выбранную пользователем папку; приложение не печатает их автоматически и не
изменяет данные клиентов, счетов или документов ABS.

Кнопки «Выше» и «Ниже» задают порядок подготовки файлов к ручной печати.
TLS-режим запуска сохранён совместимым с существующим BAT (`--insecure`).
