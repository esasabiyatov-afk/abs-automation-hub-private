# Поиск клиентов Tolubay: готовый материал для ИИ и разработчика

## Назначение

`client_lookup.py` выполняет только чтение:

1. Ищет физлиц по ИНН/ФИО и юрлиц по ИНН/наименованию организации.
2. Если совпадений нет, возвращает `found: false` и `Клиент не найден`.
3. Для каждого найденного клиента получает анкету и оставляет в результате
   только выбранные поля.
4. Получает активные и закрытые счета в компактном виде.
5. Позволяет отключать отдельные поля через `client_lookup_fields.json`.
6. Возвращает `Клиент не найден` только для корректной пустой
   таблицы ABS; тайм-аут, сбой авторизации или нестандартный ответ считаются ошибкой.

Версия 0.5.3 использует штатный AJAX-контракт поиска АБС: POST на
`/Customers/SearchResult` со всеми полями формы и заголовком
`X-Requested-With: XMLHttpRequest`. Для `client_lookup.py` включён отдельный
профиль `lookup_only`: из POST-маршрутов разрешены только вход, поиск и
получение счетов. Маршруты отчётов и заданий в этом профиле блокируются.

Удаление, закрытие, восстановление и сохранение анкеты блокируются модулем
`ReadOnlyPolicy`.

## Требования

- Python 3.11 или новее.
- Доступ к `https://ob.tolubay.kg` из сети рабочего компьютера.
- Логин и пароль пользователя АБС с разрешением на просмотр нужных данных.
- Корневой сертификат банка в Windows либо путь в `TOLUBAY_CA_FILE`.

Chrome, Selenium, WebDriver и интернет для установки библиотек не нужны.

## Запуск

### Самый простой способ

Дважды щёлкните `START_CLIENT_LOOKUP.bat`, выберите поиск по ИНН или ФИО и
следуйте подсказкам. Для ОсОО и других юрлиц выберите пункт 3 — поиск по
наименованию организации. Результат показывается только в окне BAT и не
сохраняется программой в JSON-файл. В этой сборке батник всегда передаёт `--insecure`,
поскольку АБС использует недоверенную для portable Python цепочку сертификатов.
Адрес по-прежнему жёстко ограничен `https://ob.tolubay.kg`.

### Запуск из PowerShell

Из каталога `automation-hub` (включая изолированный portable Python):

```powershell
$env:TOLUBAY_LOGIN = "логин"
$env:TOLUBAY_PASSWORD = "пароль"

& "C:\Users\Карабаева Ж\Documents\Python_portable\python.exe" -X utf8 `
  client_lookup.py --inn "12345678901234"
```

Поиск по ФИО:

```powershell
python client_lookup.py --fio "Фамилия Имя Отчество"
```

Поиск ОсОО или другого юридического лица по наименованию:

```powershell
python client_lookup.py --company "Название организации"
```

Несколько клиентов одним запуском:

```powershell
python client_lookup.py `
  --inn "12345678901234" `
  --inn "98765432109876" `
  --fio "Фамилия Имя Отчество" `
  --fio "Другая Фамилия Имя"
```

`--inn` и `--fio` можно повторять любое количество раз. Для ФИО принят порядок
`Фамилия Имя Отчество`. `--company` также можно повторять. Если известно только имя или фамилия, лучше передавать
точные поля напрямую через `TolubayClient.search_customers`.

## Формат результата

```json
{
  "поиск": [
    {
      "тип": "ИНН",
      "значение": "...",
      "найден": true,
      "сообщение": "Найдено клиентов: 1"
    }
  ],
  "клиенты": [
    {
      "ФИО": "...",
      "ID_в_ABS": "...",
      "паспорт": {
        "тип_документа": "...",
        "серия": "...",
        "номер": "...",
        "кем_выдан": "...",
        "дата_выдачи": "...",
        "действителен_до": "..."
      },
      "ИНН": "...",
      "адрес_проживания": "...",
      "адрес_прописки": "...",
      "дата_рождения": "...",
      "телефоны": ["..."],
      "количество_счетов": 1,
      "счета": [
        {
          "статус": "активный",
          "валюта": "KGS",
          "наименование_счета": "...",
          "номер_счета": "...",
          "дата_открытия": "...",
          "дата_закрытия": ""
        }
      ]
    }
  ]
}
```

Для юрлица вместо ФИО, паспорта и даты рождения возвращаются:

- `ID_в_ABS`;
- `наименование_организации`;
- `организационно_правовая_форма`;
- `ИНН` и `ОКПО`;
- `регистрационный_номер`, `дата_регистрации`, `орган_регистрации`;
- `юридический_адрес` и `фактический_адрес`;
- телефоны, количество счетов и те же компактные данные счетов.

## Как убрать ненужные поля

Откройте `client_lookup_fields.json` обычным Блокнотом. У нужного поля замените
`true` на `false`. Например, чтобы убрать телефоны и дату закрытия счёта:

```json
{
  "customer": {"phones": false},
  "account": {"close_date": false}
}
```

Остальные отсутствующие в укороченном файле переключатели сохраняют значение
по умолчанию. Доступные разделы: `customer`, `passport`, `legal`, `account`. Изменения
применяются при следующем запуске BAT, исходный код менять не нужно.

## Интеграция в другое приложение

```python
from automation_hub.tolubay import TolubayClient, TolubayConfig

client = TolubayClient(TolubayConfig())
client.login(login, password)

customers = client.search_customers({"SearchIdentificationNo": inn})
if not customers:
    print("Клиент не найден")
else:
    for customer in customers:
        questionnaire = client.get_customer_questionnaire(customer.customer_id)
        accounts = client.get_accounts(customer.customer_id, include_closed=True)
```

## Безопасность

- Не помещать логин и пароль в исходный код.
- Не отправлять полученный JSON в публичные ИИ или публичные репозитории.
- Результат выводится только на экран: параметр `--output` в этой сборке
  отсутствует.
- Не добавлять маршруты Save, Edit POST, Delete, Close или Restore в allowlist.
